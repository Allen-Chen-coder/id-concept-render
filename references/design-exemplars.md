# 设计典范库（按产品品类分类）

> 第 2 步"定审美方向"时，先按品类找到本小节，选 1–2 个典范作为**标杆锚点**写进提示词第 5 层（渲染风格层），或作为第 6 步创新方法的迁移对象。每个条目给出可直接复制的提示词短语。
> 用法：品类常识告诉你这个品类的"形态约束与 CMF 惯例"，典范告诉你"这个品类的天花板长什么样"。

## 目录

- 一、穿戴与随身设备（领夹 / 手环 / 手表 / 戒指 / 录音笔）
- 二、音频设备（音箱 / 耳机 / 麦克风）
- 三、3C 桌面配件（充电器 / 鼠标 / 键盘 / 存储）
- 四、小家电与个护（吹风机 / 剃须刀 / 牙刷 / 咖啡机）
- 五、家居硬件（音箱 / 温控 / 门锁 / 摄像头）
- 六、医疗健康（血压计 / 体脂秤 / 助听器 / 健康监测）
- 七、工具与仪器（测距仪 / 万用表 / 电动工具 / 相机）
- 八、出行与户外（自行车 / 滑板车 / 背包配件）
- 九、使用规则

## 一、穿戴与随身设备

**品类常识**：重量是第一约束（领夹 <20 g、腕戴 <30 g）；接触面必须圆滑；固定机构要可信；灯效走光导/光环，不走裸灯珠；CMF 惯例是"哑光壳 + 一处金属或织物触点"。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Apple Watch（铝合金版） | 一体成型铝壳 + 数码表冠：把"精密仪器"缩到腕上，表冠是形态记忆点 | `seamless aluminum unibody, knurled digital crown as the hero detail` |
| Oura Ring | 钛合金无缝卵石环：把传感器藏进珠宝形态，证明"无感穿戴"的极致是让用户忘记设备 | `seamless aerospace-titanium pebble form, jewelry-like finish, sensor invisibility` |
| Plaud Note（AI 卡片录音机） | 卡片式轻薄机身 + 磁吸背夹：录音设备脱离"笔"的惯例形态，商务无感 | `credit-card-thin slab, magnetic clip, discreet business tool` |
| 讯飞智能录音笔 H1 系列 | 金属机身 + 领夹一体：中文 B 端录音硬件的商务范式，按键与录音灯语义清晰 | `machined metal body, integrated collar clip, clear record-button and LED semantics` |
| Whoop 4.0（无屏手环） | 去掉屏幕只靠织带与本体：信息全部在 APP，设备回归纯粹 | `screenless minimal band module, fabric strap, no display at all` |

## 二、音频设备

**品类常识**：出声孔/网罩是品类的"脸"，孔阵设计即品牌语言；材质对撞（金属×织物、木×铝）是高级感的常规手段；旋钮/按键要有阻尼感暗示。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Bang & Olufsen Beosound 系列 | 阳极铝壳 + 精密冲孔网罩：把声学开孔做成装饰图形，工艺即设计 | `anodized aluminum shell with precision-drilled acoustic perforation pattern` |
| Teenage Engineering OP-1 / OB-4 | 平面设计 + 旋钮即图形元素：功能可见化与玩具感的边界拿捏 | `flat graphic design, colorful knobs as composition elements, playful precision` |
| Apple AirPods Max | 阳极铝耳罩 + 织物头梁对撞：两种材质各说各的话（耐用×舒适） | `anodized aluminum ear cups contrasted with woven knit headband` |
| Marshall 音箱系列 | 皮革纹理 + 黄铜旋钮 + 手写体 logo：复古未来主义的完整叙事 | `black vinyl leather texture, brass control knobs, retro-futuristic amp aesthetic` |
| Sony WF-1000XM5（降噪豆） | 回收塑料做出哑光质感：低成本材料靠纹理与造型撑住高级感 | `fine matte texture on recycled plastic, pebble-like earbuds` |

## 三、3C 桌面配件

**品类常识**：桌面小件靠"轮廓 + 表面质量"取胜；消费级白色家电感 vs 专业级石墨金属感是两条分水岭；隐藏线缆/接口是默认要求。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Apple 妙控板 / 妙控鼠标 | 纯白 + 铝底的双材质语言，轮廓由圆角矩形精确控制 | `white matte top with precision aluminum base, exact corner radii` |
| Anker Prime 系列充电器 | 哑光黑 + 一块小显示屏：在极简轮廓上放一个"功能性点缀" | `matte graphite shell with one small functional display as accent` |
| Native Union 配件线 | 织物编织 + 金属配重块：把耗材做成桌面物件 | `braided fabric cable with weighted aluminum dock` |
| LaCie（Neil Poulton 设计硬盘） | 金属边框包硅胶芯：防护结构与外观一体化 | `aluminum rim wrapping a soft silicone core, rugged elegance` |
| Logitech MX 系列 | 石墨灰商务语言 + 人体工学曲面：B 端办公设备的审美安全牌 | `graphite gray business aesthetic, ergonomic sculptural surfaces` |

## 四、小家电与个护

**品类常识**：风道/水路等功能结构可以成为造型主体（戴森范式）；手持件必须有明确的握持区与重心；个护产品允许更柔和的色彩。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Dyson Supersonic | 中空环形风道 = 功能可见化：把手柄做细、马达进手柄，形态跟着工程走 | `hollow annular airflow head, engineering-driven form` |
| 博朗 Braun 剃须刀（Rams 传统） | 几何秩序 + 纹理分区：每个面有明确的功能归属 | `geometric order, textured grip zones, Dieter Rams discipline` |
| 巴慕达 BALMUDA 电水壶/烤面包机 | 克制的几何 + 单一材质：用最少的元素建立高端家居感 | `restrained geometry, single-material honesty, quiet premium` |
| Oral-B iO 电动牙刷 | 圆润单体 + 状态灯环：把交互灯做成形态的一部分 | `monolithic rounded body, light ring integrated at the neck` |
| Nespresso 胶囊机（极简线） | 悬臂 + 杯区的正负形关系：小家电的雕塑化处理 | `cantilevered brew head, sculpted negative space for the cup` |

## 五、家居硬件

**品类常识**：家居设备是"电子家具"，材质要能和木材/织物共存；灯光类产品的光是本体；越常驻家中的设备越要弱化"电子产品感"。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Google Nest Thermostat | 圆形玻璃面 + 金属外环：温控器变成墙上的装饰物 | `circular glass face with rotating metal ring` |
| B&O Beoplay A9 / Balance | 雕塑化几何 + 织物/木腿：音箱先是一件家具 | `sculptural geometric speaker, fabric front, wooden legs` |
| 无印良品香薰机（深泽直人系） | 磨砂白圆柱 + 雾气：材质诚实 + 氛围营造 | `frosted white cylinder, soft diffused mist glow` |
| 鹿客/小米智能门锁 | 一体化黑镜面板 + 隐藏键盘：把"锁"的复杂收进一个面 | `monolithic dark glass panel, keypad hidden until lit` |
| Nanoleaf / Philips Hue 灯带系统 | 光即形态：产品本体退后，光效成为设计 | `light as the primary form, minimal visible hardware` |

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Omron 上臂式血压计 | 纯白圆角 + 织物袖带一体收纳：医疗设备的亲和力范本 | `clean white rounded monolith, integrated fabric cuff storage` |
| Withings 体脂秤/手表 | 玻璃 + 金属环的健康监测：医疗数据装进生活方式外观 | `tempered glass with slim metal ring, lifestyle-medical hybrid` |
| Signia Styletto（助听器） | 纤细如蓝牙耳机：把"助听"的羞耻感做成时尚配件 | `slim earpiece form factor, fashion-accessory finish` |

## 七、工具与仪器

**品类常识**：工具的语言是"可信"——材质要耐摔、按键要大、色彩分区有工程惯例（黄=测量、蓝=Bosch 系、红=Milwaukee 系）；精密仪器允许"细节密度高"。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| Leica M 系列相机 | 黄铜顶盖 + 皮革饰皮 + 精密拨轮：精密仪器的永恒范式 | `brass top plate, leatherette grip, precision machined dials` |
| Leica Disto 激光测距仪 | 黄黑工程配色 + 单手楔形：配色即品类语言 | `iconic yellow-black engineering colorway, one-hand wedge form` |
| Fluke 万用表 | 黄灰保护胶套 + 大转盘：防护结构与握持一体 | `yellow-gray protective rubber holster, large rotary selector` |
| Bosch 12V 工具家族 | 统一的蓝黑语言 + 软胶握持区：系列化设计的系统感 | `consistent blue-black family language, soft-grip zones` |
| Teenage Engineering 的 field 系列 | 铝型材 + 橙色点缀：把仪器做成"想要拥有的物件" | `anodized aluminum extrusion, single orange accent` |

## 八、出行与户外

**品类常识**：户外产品允许更高的色彩饱和（可视性即安全）；结构件可以外露（折叠机构、铰链是设计特征）；一体化灯语是近年出行设备的创新富矿。

| 典范 | 为什么是典范 | 提示词迁移短语 |
|---|---|---|
| VanMoof 电动自行车 | 铝架内走线 + 一体化前后灯带：灯语成为品牌签名 | `integrated front and rear light bars in the aluminum frame` |
| 小米电动滑板车 | 折线几何 + 隐藏走线：千元级的秩序感 | `folding geometric frame, fully hidden cable routing` |
| Peak Design 背包配件 | 铝钩 + 织带的机构外露：把连接机构做成视觉特征 | `exposed aluminum hook-and-strap hardware as design feature` |
| Garmin 户外表 | 金属表圈 + 螺钉外露：粗犷的可信感 | `exposed screws on metal bezel, rugged tool-watch aesthetic` |

## 九、使用规则

1. **每案限锚 1–2 个典范**：锚点是"完成度参照"而非"形态复制"，写在提示词第 5 层（渲染风格层），不要整段抄形态描述进第 2 层。
2. **跨品类迁移是创新来源**：把 A 品类的典范语言迁到 B 品类（如把出行设备的灯语迁移到随身录音设备的光环缝），就是 innovation.md 的"类比迁移"法，迁移后要过一遍品类常识约束。
3. **典范也有成本档位**：Leica/Oura 是高端档锚点，给 B 端低成本产品锚定时，只取"设计语言"不取"工艺"（取其形态秩序，用 cost-dfm.md 的低成本 CMF 落地）。
4. 本库未覆盖的品类：按相邻品类借锚 + 品类常识自行推导，并把新典范补回本文件（迭代原则）。
